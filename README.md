# 60秒教材アニメーション「お礼状の8つの基本」

特別支援学校高等部・国語の授業用。お礼状の8つの構成（宛名 → 頭語 → 時候の挨拶 → 主文 → 用件 → エピソード → 結びの挨拶 → 結語）を、約60秒のアニメーションで見せる教材です。
HTML / CSS / JavaScript だけで動きます（外部ライブラリなし、サーバー不要）。

## ファイル構成

```
index.html                         画面の枠（文章は書いていません）
style.css                          見た目・アニメーション
app.js                             再生のしくみ（教材データを読んで表示）
assets/icons.js                    アイコン（SVG）
assets/lessons/thank-you-letter.js 教材データ（文章・色・秒数）
```

## 使い方

- `index.html` をブラウザで開くと自動再生されます（ダブルクリックでもOK）。
- 画面下のボタン：**最初から見る** / **一時停止・再生** / **ふりがな** の表示切り替え / **全画面**
- 映像をクリックしても一時停止・再生できます。

| キー | 動作 |
| --- | --- |
| スペース | 一時停止／再生 |
| R | 最初から再生 |
| F | ふりがなの表示／非表示 |
| ← / → | 前の場面／次の場面 |

別のタブに切り替えると自動で一時停止し、戻ると再開します。
OSで「視差効果を減らす／アニメーションを減らす」を設定している場合（`prefers-reduced-motion`）、動きの少ないフェード表示になります。

## 場面と再生時間（合計60秒）

| 時間 | 場面 |
| --- | --- |
| 0〜5秒 | タイトル「お礼状には8つの基本があります」→「順番に見てみよう！」 |
| 5〜9秒 | 8つの一覧「この順番で書きます」 |
| 9〜14秒 | ① 宛名 |
| 14〜19秒 | ② 頭語（拝啓） |
| 19〜24秒 | ③ 時候の挨拶（春夏秋冬 → 秋） |
| 24〜29秒 | ④ 主文 |
| 29〜34秒 | ⑤ 用件 |
| 34〜39秒 | ⑥ エピソード |
| 39〜44秒 | ⑦ 結びの挨拶 |
| 44〜49秒 | ⑧ 結語（拝啓 → 敬具） |
| 49〜56秒 | 順番の確認「この順番を覚えよう！」 |
| 56〜60秒 | まとめ「気持ちが伝わるお礼状を書こう！」＋封筒が閉じる |

## 文章・秒数を変えるには

`assets/lessons/thank-you-letter.js` だけを編集します。

- 秒数：各場面の `duration: 5` を `duration: 7` などに変更（合計時間は自動計算）
- 文章の書き方：
  - `{漢字|かんじ}` … ふりがな付き
  - `*ことば*` … マーカーで強調
  - `\n` … 改行
- 色：`items` の `color`
- アイコン：`icon` / `icons` に `assets/icons.js` の名前を指定

## 別の教材に流用するには

1. `assets/lessons/thank-you-letter.js` をコピーして、例えば `assets/lessons/keigo.js` を作る
2. `id`・`items`（項目）・`scenes`（場面）を書き換える
3. `index.html?lesson=keigo` で開く（または `index.html` の読み込み先を変更）

使える場面の型：

| type | 内容 | 主な設定 |
| --- | --- | --- |
| `title` | タイトル（封筒） | `lines`, `sub`, `subAt` |
| `overview` | 項目のカード一覧 | `heading`, `headingAt` |
| `step` | 項目1つの説明＋便箋の例文 | `item`, `desc`, `example`, `effect`, `icons`, `size`, `align`, `extra` |
| `flow` | 縦に並べて順番に光る | `heading`, `start`, `interval` |
| `ending` | まとめ＋封筒が閉じる | `lines`, `chainBreak` |

`step` の `effect`：`drop`（上から置く）/ `write`（1文字ずつ書く）/ `fade` / `soft`（やわらかく＋ハート）/ `check`（チェック）/ `glow`（星）/ `gather`（文字がまとまる）
`step` の `extra`：`seasons`（季節）/ `note`（小さな補足）/ `pair`（セットの言葉）

## GitHub Pages で公開する

1. このリポジトリを GitHub に push する
2. GitHub のリポジトリ画面 → **Settings** → **Pages**
3. **Source** を「Deploy from a branch」、Branch を `main`（または公開したいブランチ）・フォルダを `/ (root)` にして **Save**
4. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` を開く

※ フォントは Google Fonts（BIZ UDPゴシック、Klee One）を使います。インターネットにつながらない環境では、パソコンに入っているフォントで表示されます。
